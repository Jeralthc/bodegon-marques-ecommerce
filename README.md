## 📌 Resumen del Proyecto

Este repositorio contiene la **investigación profunda**, la **propuesta arquitectónica de modernización** y el **Mockup Web Interactivo de Alta Gama** especialmente diseñado para **Licores Mundiales**, adaptando su identidad visual oficial, su trayectoria desde 1973, su sede insignia de Las Mercedes y la esencia de su comunidad en Instagram (`@licoresmundiales`).

## 🚀 Cómo Visualizar el Mockup y Presentarlo al Cliente

### 1. En la Web (Totalmente Interactivo)
Abre directamente: **[https://jeralthc.github.io/licores-mundiales-redesign/](https://jeralthc.github.io/licores-mundiales-redesign/)**
- Selector multimoneda activo: **USD ($)**, **Bolívares (Bs.)** y **EUR (€)**.
- **Sommelier Virtual LM:** Asistente interactivo que recomienda etiquetas según ocasión (Cena de Gala, Regalo Ejecutivo, Cata de Colección, Brindis).
- **Fichas de Cata Sensoriales:** Notas de *Nariz, Boca, Final y Maridaje* para cada botella.
- **Carrito con Despacho de Caracas:** Selección entre *Delivery Same-Day Caracas* y *Retiro en Sede Las Mercedes (&lt; 45 min)*.
- **Orquestación de Pagos:** Soporte visual de Pago Móvil, Zelle, Tarjeta Internacional y Efectivo en Cava.
- **Enlace directo a WhatsApp Concierge y a Instagram `@licoresmundiales`**.

### 2. En Figma
1. Abre Figma y utiliza el plugin gratuito **[html.to.design](https://www.figma.com/community/plugin/1159128335372329272)**.
2. Ingresa la URL: `https://jeralthc.github.io/licores-mundiales-redesign/`
3. Se generarán automáticamente los lienzos vectoriales con Auto Layout para Desktop y Mobile.
4. Carga el archivo `figma-tokens.json` con el plugin **Tokens Studio for Figma** para vincular la paleta oficial (Borgoña Tinto, Oro Líquido, Negro Cava).
